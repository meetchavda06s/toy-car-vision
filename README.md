# Toy Car Vision

Global vision tracker for small toy cars. Reads from a video file **or** a
live webcam, detects each configured car by colour, tracks it with a Kalman
filter, maps image pixels to real-world millimetres via a homography, and
broadcasts the results on UDP (or logs to a file).

Works on **any** video of a toy car on a flat field — nothing in the code is
specific to one clip. Setup for a new video is three steps.

## 1. Install

```bash
pip install -r requirements.txt
```

## 2. Set up a new video (one-time per field layout)

```bash
# a) teach the system where real-world (x, y) is
python scripts/setup_homography.py --source data/test_videos/mine.mp4

# b) teach it what the car looks like
python scripts/register_car.py --source data/test_videos/mine.mp4 --name RedRacer

# c) point default.yaml at the new video (or pass --source at run time)
```

The homography script shows a frame; click 4+ reference points (field
corners, floor markers, ArUco tags...), then type each one's known
real-world mm coords. The car-register script shows a frame; click a few
pixels on the car and the HSV range is written to `config/default.yaml`.

## 3. Run

```bash
# default: UDP broadcast + annotated video output
python run.py

# or point at a specific file + port
python run.py --source data/test_videos/mine.mp4 --port 5000

# offline/headless (fastest):
python run.py --no-visual --mode log
```

## 4. Evaluate

```bash
# ROC curve (needs hand-labelled frames: evaluation/ground_truth/labels.csv)
python evaluation/roc_curve.py

# Mapping error (needs reference points: evaluation/ground_truth/reference_points.csv)
python evaluation/mapping_error.py
```

## Folder layout

```
toy-car-vision/
├── run.py                     # entry point
├── config/
│   ├── default.yaml           # all tuneable parameters
│   └── homography.yaml        # generated by setup_homography.py
├── src/
│   ├── camera.py              # file/webcam capture
│   ├── detector.py            # HSV multi-car detector
│   ├── tracker.py             # Kalman + Hungarian multi-tracker
│   ├── homography.py          # pixel ↔ world mm
│   ├── output.py              # UDP + log
│   ├── visualise.py           # overlays + output video
│   ├── pipeline.py            # orchestrator
│   └── utils.py
├── scripts/
│   ├── setup_homography.py    # interactive 4-point calibration
│   └── register_car.py        # interactive HSV sampler
├── evaluation/
│   ├── roc_curve.py           # TPR vs FPR plot
│   └── mapping_error.py       # position-error analysis
└── outputs/                   # annotated videos + log files
```

## Output format

Each tracked car emits one line per frame, matching the assignment spec:

```
<timestamp_us>:"<name>",x,y,theta,vx,vy,omega,u,v
```

A missed car reports `-1000.0,-1000.0` for `x,y`.
